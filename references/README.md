# Materiais de referência

Objetivo: Identificar os materiais de apoio e distingui-los dos recursos usados pelo portal.

- `pdf/`: fluxogramas recebidos sobre os fluxos de informações do projeto.
- `jpeg/`: imagens de apoio que estavam soltas na raiz.

As imagens carregadas diretamente pelo portal ficam em `static/img/`.
Estes materiais foram movidos sem alteração de conteúdo.
